# Alice-Desktop-Pet
This is a desktop pet, and the pet character is a reporter from the game "Identity V." This product was created with GPT assistance, supports login functionality, features 120-frame animated actions, and also includes various functions like weather, clock, ecosystem, focus, and memorials.
