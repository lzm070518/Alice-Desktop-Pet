# Alice 桌面宠物 3.2.2 普通版

**从 3.2.1 升级时，请先退出 Alice，直接运行 `Alice-3.2.2-Setup.exe`。请勿先卸载 3.2.1，旧卸载程序会删掉个人资料。**

## 外观和动画

Alice 换上了与 ChatGPT 桌宠同款的猫耳造型。待机、注视、打招呼、跳跃和小跑等动作采用这套角色的图像，阅读、记笔记、喝茶和拍照保留了相应道具。31 个连续动作保留原来的播放时长，部分专属动作使用含义相近的姿势。

小跑的一秒循环包含 120 张不同画面。右击桌宠，在「设置 → 动画帧率」中可选 30、60 或 120 FPS。120 FPS 是播放目标，屏幕刷新率和设备负载会影响实际显示。

## 豆包和 OpenAI

在「设置 → AI / API 设置」中可选择「豆包（火山方舟）」或「OpenAI / ChatGPT」。同页的「豆包 / ChatGPT 指南」说明了怎样填写地址、模型和自己的 API 密钥。API 开通、权限和费用由所选服务商管理。

## 安装与个人资料

适用于 Windows x64。首次安装默认写入当前用户的 `%LOCALAPPDATA%\Programs\Alice`，也可以选择其他目录。覆盖安装时会沿用原普通版安装目录，个人设置、日历等继续从 `%APPDATA%\Alice` 读取。3.2.2 的卸载程序保留用户资料。

Windows 文件版本为 `3.2.2.0`，桌宠设置显示「版权 3.2.2」。版权页的「原版号 3.2.1」来自原作者签发的历史版权记录。本普通版重建发行包以随附 SHA-256 作完整性校验。

## 校验下载

在安装包所在目录打开 PowerShell，执行以下命令，将结果与附件中的 `SHA256SUMS.txt` 对照。

```powershell
Get-FileHash -Algorithm SHA256 .\Alice-3.2.2-Setup.exe
```
