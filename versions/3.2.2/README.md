# Alice 3.2.2 用户版

[下载 Windows 64 位安装程序](https://github.com/lzm070518/Alice-Desktop-Pet/releases/download/v3.2.2/Alice-3.2.2-Setup.exe) · [查看版本目录中的安装文件](Alice-3.2.2-Setup.exe)

**从 3.2.1 升级，请先退出 Alice，再直接覆盖安装。请勿先卸载 3.2.1，旧卸载程序会删除个人资料。**

本版使用与 ChatGPT 桌宠一致的猫耳角色素材，小跑的一秒循环包含 120 张不同画面。设置支持 30、60 和 120 FPS，实际显示取决于屏幕和设备。在「AI / API 设置」内可查看豆包与 OpenAI / ChatGPT 的接入指南。
