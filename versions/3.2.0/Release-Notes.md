## Alice 3.2.0

- 更新31项连续动作，保持正常动作时长，采用完整关键姿势与离线补帧的120FPS时间线。
- 保留已经确认的小跑，以及比心等可爱的定格表情。
- 饭点吃饭使用完整人物、饭盒和勺子的一体动作，生态设置可直接“试播吃饭”。
- 补齐阅读、记笔记、喝茶、舞步、鞠躬和整理蝴蝶结中被裁掉的24个关键姿势。
- 固定角色比例和接触点，取消这些动作额外的旧身体拉伸和逐帧贴底移动。
- 246页无损动作资源均通过与PNG原素材逐字节一致性检查；复用缩放计算和重复关键姿势缓存。
- 保留天气卡片布局修复、API聊天配置、账号注册登录和已有陪伴工具。

### 下载与升级

Windows 64位：下载 **Alice-3.2.0-Setup.exe**。本次公开发布仅包含用户版。

先退出对应旧版，再覆盖安装。不要先卸载，以保留资料；安装可选C盘、D盘或自定义目录。本次无需操作Neon或重新填写现有API配置。

本版采用离线补帧，并非每秒120张独立手绘原画。实际显示帧率取决于设备和屏幕。自动化测试、定向竞态、混淆后功能检查、版本与安装包内容校验通过；本构建环境未进行Windows桌面实机安装测试。
