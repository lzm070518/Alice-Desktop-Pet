# Alice 3.2.1 · 聊天响应优化

- 已知支持思考开关的豆包 Seed、新版 DeepSeek 官方模型默认优先快速回答。
- API 设置新增“使用模型默认思考模式”，复杂任务可勾选保留模型原行为；每个服务分别记住，并随加密配置备份。
- 合并流式文字更新，避免繁忙界面让回复排队；只更新聊天内容，减少标题和头像重绘。
- 收到回答结束信号即恢复发送，不再等待网关关闭长连接。
- 显示首段回答和总耗时，方便了解接口响应。

未知接口、ep- 接入点和其他模型保持原请求方式；不静默切换模型，不截短回答。原版形象、已定稿动作、聊天历史与 API 配置保留。本次无需重新执行 Neon SQL。

退出旧版后覆盖安装；安装目录仍可选 C 盘、D 盘或自定义路径。只公开用户版，历史版本与旧下载链接继续保留。

模拟接口、竞态检查、Windows 编译、版本和发行清单校验通过。实际速度取决于模型、服务商负载和网络；未使用用户密钥进行付费实测，未完成 Windows 实机安装验证。
