# Alice 3.2.3 普通版

适用于 Windows 64 位。[下载 Alice 3.2.3 安装程序](https://github.com/lzm070518/Alice-Desktop-Pet/releases/download/v3.2.3/Alice-3.2.3-Setup.exe)

## 菜单与窗口

3.2.3 调整了菜单和功能窗口的显示顺序。从桌宠菜单打开登录等功能后，可以直接在新窗口中操作，避免原菜单遮住按钮。普通版的快捷方式和开机启动入口使用新的本地启动器。

本版沿用 3.2.2 的经典桌宠核心、ChatGPT 同款角色素材和 30、60、120 FPS 设置。动画、账户、AI 聊天和 API 设置继续使用原普通版的资料。120 FPS 为播放目标，实际呈现取决于屏幕和设备。

## 安装与升级

先退出正在运行的 Alice，再运行本版安装程序覆盖安装。**从 3.2.1 升级时，请保留现有安装并直接覆盖。3.2.1 的旧卸载程序会删除个人资料。** 本版卸载程序保留普通版个人资料。
